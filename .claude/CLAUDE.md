# Project Instructions

## Committing Work

Commit and push to `main` as soon as a feature or fix is finished. Do not wait to be asked, and do not batch several features into one commit.

"Finished" means the change is complete and verified: the backend compiles, `npx tsc -b` and `npm run build` pass in `src/frontend` when frontend files changed, and any new logic has been exercised. Commit each feature on its own as it lands.

## Git Commits

NEVER add yourself as a co-author on any commit. Do not include `Co-Authored-By` trailer lines in any commit message. This breaks project management software.

Commit messages should be authored solely by the git user — no exceptions.
